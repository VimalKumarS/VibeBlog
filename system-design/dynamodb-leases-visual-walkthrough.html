Distributed coordination · visual walkthrough

One connection.
One owner.
Automatic recovery.

A DynamoDB lease is a time-limited claim on a long-lived stream. Conditional writes stop two workers from claiming it at once; heartbeats preserve healthy ownership; reconciliation repairs abandoned work.

The lock is not permanent.

That is the resilience mechanism. A dead worker cannot renew, so its claim eventually becomes acquirable without an operator or a separate coordinator.

SQS = speedNotifies workers immediately that new work exists.
DynamoDB = truthStores desired state, owner, expiry, and resume point.
Heartbeat = livenessExtends ownership while the worker stays healthy.
Reconciler = repairFinds expired STARTED records and reassigns them.

05 / CORE CODE

Three conditional operations

The implementation is mostly ordinary async I/O. The correctness lives in the conditions attached to acquire, renew, and release.

async def claim(key, worker_id):
    now = epoch_ms()
    try:
        result = table.update_item(
            Key={"pk": key},
            UpdateExpression="SET lease_owner=:me, lease_expires_at_ms=:until",
            ConditionExpression=(
                "attribute_not_exists(lease_expires_at_ms) "
                "OR lease_expires_at_ms < :now"
            ),
            ExpressionAttributeValues={
                ":me": worker_id,
                ":now": now,
                ":until": now + LEASE_MS,
            },
            ReturnValues="ALL_NEW",
        )
        return result["Attributes"]
    except ConditionalCheckFailed:
        return None  # a different worker won
async def heartbeat(key, worker_id):
    now = epoch_ms()
    try:
        table.update_item(
            Key={"pk": key},
            UpdateExpression="SET lease_expires_at_ms=:until",
            ConditionExpression="lease_owner=:me",
            ExpressionAttributeValues={
                ":me": worker_id,
                ":until": now + LEASE_MS,
            },
        )
        return True
    except ConditionalCheckFailed:
        return False  # close the socket; ownership was lost
async def repair_loop():
    while not stopping.is_set():
        await asyncio.sleep(RECONCILE_SECONDS)

        expired = table.query(
            IndexName="desired-state-expiry-index",
            KeyConditionExpression=(
                "desired_state=:started "
                "AND lease_expires_at_ms < :now"
            ),
            ExpressionAttributeValues={
                ":started": "STARTED",
                ":now": epoch_ms(),
            },
        )

        for item in expired["Items"]:
            owned = await claim(item["pk"], WORKER_ID)
            if owned:  # losers simply continue
                asyncio.create_task(run_socket(owned))

Production guardrails

The lease solves coordination, not every delivery guarantee.

Synchronize clocksWorkers supply “now”; monitor NTP drift and budget for skew.
Checkpoint + deduplicateA lease gives one current owner, not exactly-once message processing. Persist sequence IDs and make writes idempotent.
Fence stale workersFor strict downstream exclusion, include a monotonically increasing lease version in writes.
Batch state checksAt scale, replace one read per connection with centralized BatchGetItem.
Back off after losingA failed condition is normal contention, not an incident.
07 / MENTAL MODEL

What to say in a system-design interview

Describe the responsibilities separately: notification, durable ownership, failure detection, and recovery.

Why not SQS alone?

SQS delivers work, but it does not model continuously renewed ownership or answer “who owns this stream now?”

Why conditional writes?

They turn a race into one atomic decision. One update commits; every loser receives a condition failure and backs off.

What bounds recovery?

For an ungraceful crash: roughly lease duration + up to one reconciliation interval. Graceful release skips the expiry wait.

Based on the AWS Architecture Blog pattern for an ECS/Fargate fleet of outbound WebSocket workers. Defaults shown here—5-second heartbeat, 20-second lease, 60-second reconciliation—come from that reference architecture and should be tuned.
