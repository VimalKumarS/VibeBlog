03 / THE OOM FIX

Count tokens, not requests

A fixed number of requests says nothing about the memory they need. Sequence lengths can vary wildly, so the scheduler budgets the scarce resource directly.

05 / WHY IT MATTERS

BEI is the RAG data plane

LLM serving gets the attention, but retrieval quality and latency are shaped upstream. Embeddings find candidates; rerankers reorder them; the generator sees only the final context.

1 · Embed

Turn the query and corpus into vectors. Batch ingestion wants throughput; the live query wants low latency.

2 · Retrieve + rerank

Fetch approximate candidates, then run a more precise scoring model over a smaller set.

→
3 · Generate

Hydrate the prompt with the best context and let the LLM produce an answer.

What transfers from vLLM

  • Continuous admission and queue discipline
  • GPU utilization depends on batch composition
  • Kernel and memory traffic dominate hot-path efficiency
  • Autoscaling must account for queue depth and cold starts

What changes for embeddings

  • No autoregressive decode loop or KV-cache growth
  • Outputs are numerical, so the return path is simpler
  • Sequence packing is central to handling length variance
  • Batch corpus work and live query traffic coexist
06 / REMEMBER THIS

Six system-design lessons

If you explain BEI in an interview or design review, lead with workload shape and resource budgeting—not the brand name of a kernel.

Start with two SLOs

Batch ingestion optimizes tokens per second; real-time querying optimizes tail latency and concurrency.

Budget the real bottleneck

Token count predicts memory pressure better than request count when sequence lengths vary.

Move work off the GPU path

Parallel CPU tokenization prevents text preprocessing from starving expensive accelerators.

Backpressure is part of inference

Queues, async completion, and graceful scale-up/down determine whether the model server survives bursts.

Optimize memory movement

Batching, fused layers, and lower precision all raise useful computation per byte transferred.

Benchmark the whole service

Network routing, colocation, scheduling, and cold starts can outweigh kernel speed in production.
